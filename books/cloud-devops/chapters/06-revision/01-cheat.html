The cheat sheet

Every concept in one or two lines, with the food-court picture that helps you remember it.

Foundations and running code

ch {{n:ch-cloud-basics}}
Service models

Empty shell (IaaS) → equipped kitchen (PaaS) → self-lighting stove (serverless) → order in (SaaS).

ch {{n:ch-cloud-basics}}
Regions and AZs

Region = city, AZ = separate building. Deploy across 2+ AZs; second region for DR.

ch {{n:ch-cloud-basics}}
Shared responsibility

Provider secures the cloud; you secure what's in it (IAM, network, data, code).

ch {{n:ch-aws-gcp}}
Name map

EC2/GCE, S3/GCS, RDS/Cloud SQL, Lambda/Cloud Run functions, Fargate/Cloud Run, EKS/GKE, SQS/Pub/Sub.

ch {{n:ch-iam}}
IAM

Principal + action + resource + condition. Explicit deny wins. Roles/service accounts, no keys, least privilege.

ch {{n:ch-networking}}
VPC

Public subnet → IGW; private → NAT. Only the LB is public. SGs stateful, NACLs stateless.

ch {{n:ch-compute}}
Autoscaling

Keep CPU ~60%, min 2 across AZs, stateless instances, warm-up time, spot for interruptible work.

ch {{n:ch-storage-db}}
Storage

S3 objects (presigned URLs, lifecycle), EBS disks, RDS Multi-AZ for HA + replicas for reads + PITR.

ch {{n:ch-lb-dns-cdn}}
Traffic

DNS (TTL, alias) → CDN (edge cache, TLS, WAF) → L7 LB (health checks, draining) → app.

ch {{n:ch-serverless}}
Serverless and messaging

Pay per use, cold starts. Queue = one consumer, topic = fan-out. Idempotent consumers + DLQ.

Delivery and operations

ch {{n:ch-docker}}
Docker

Tiffin box. Multi-stage, JRE base, layered jar, non-root, SHA tags, logs to stdout.

ch {{n:ch-kubernetes}}
Kubernetes

Floor manager reconciling desired state. Pod → Deployment → Service → Ingress; probes, requests/limits, HPA.

ch {{n:ch-kubernetes}}
Pod failures

ImagePullBackOff (image/permission), CrashLoopBackOff (app exits / OOM 137), Pending (no capacity).

ch {{n:ch-managed-containers}}
Where to run

Cloud Run ≈ Fargate < GKE Autopilot < EKS/GKE Standard in control and effort.

ch {{n:ch-cicd}}
CI/CD

Test every commit, immutable images, OIDC not keys, GitOps, canary/blue-green with auto-rollback.

ch {{n:ch-cicd}}
DB migrations

Expand → migrate → contract; never break the running version.

ch {{n:ch-terraform}}
Terraform

Blueprint in a drawer. init → plan (review) → apply. Remote locked state, modules, drift detection.

ch {{n:ch-observability-cloud}}
Observability

Metrics → traces → logs. RED + USE. SLO 99.9% = 43 min/month. Alert on burn rate.

ch {{n:ch-cloud-security}}
Security

Defence in depth: WAF, private network, least privilege, KMS encryption, secrets manager, audit logs.

ch {{n:ch-cost}}
Cost

Tag → kill idle → right-size → Savings Plans → spot. Watch NAT, egress and log volume.
