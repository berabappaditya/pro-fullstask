Interview questions

What is Terraform state and why does it matter?

A file mapping resources in code to real infrastructure IDs and attributes. Terraform uses it to compute plans. It must be shared (remote backend) and locked so two applies don't corrupt it, and protected because it can contain secrets. Losing it means Terraform no longer knows what it manages (recover with import).

Declarative vs imperative infrastructure?

Declarative: describe the end state (Terraform, Kubernetes YAML); the tool computes the steps and is idempotent. Imperative: a script of steps (CLI commands); re-running may create duplicates or fail. Declarative tools detect and correct drift.
