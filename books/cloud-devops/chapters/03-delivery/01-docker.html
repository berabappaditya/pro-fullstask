In the food court

Ramu packs each dish in a sealed tiffin box with its own spices and cutlery, so it tastes the same in any kitchen. The packing instructions (Dockerfile) are written once; the packed tiffin (image) is stored in a cold room (registry); opening and serving one is a container. Many tiffins share one stove (the host kernel), unlike renting a whole kitchen per dish (VMs).

Interview questions

Container vs VM?

A VM virtualises hardware and runs a full guest OS on a hypervisor: strong isolation, GBs, minutes to boot. A container is an isolated process sharing the host's kernel (namespaces for isolation, cgroups for limits): MBs, starts in seconds, denser packing. Containers usually run on cloud VMs.

How do you make Docker builds fast and images small?

Order layers from least to most frequently changing (dependencies before source), multi-stage builds so build tools don't ship, slim/distroless or JRE base images, .dockerignore, Spring Boot layered jars or buildpacks, BuildKit cache mounts in CI, and scan images for vulnerabilities.

CMD vs ENTRYPOINT?

ENTRYPOINT defines the executable that always runs; CMD supplies default arguments (or the default command if there's no ENTRYPOINT) and is replaced by arguments to docker run. Use the exec (JSON array) form so the process is PID 1 and receives SIGTERM.
