Interview questions

Design the deployment of a Spring Boot REST API on AWS with high availability.

Route 53 + CloudFront/WAF → ALB in public subnets of two or three AZs → containers on ECS Fargate or EKS in private subnets (min 3 tasks across AZs, autoscaling on CPU/RPS, health checks on readiness) → RDS PostgreSQL Multi-AZ with a read replica and PITR, ElastiCache Redis, S3 for files. Secrets in Secrets Manager accessed via task/pod role. CI/CD with OIDC, image scanning, canary deploys. CloudWatch/Prometheus metrics, alarms on 5xx rate and latency, centralised logs, tracing. All defined in Terraform; separate prod account.
