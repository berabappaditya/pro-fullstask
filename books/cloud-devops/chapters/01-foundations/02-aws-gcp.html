AWS strengths

Largest service catalogue and market share, mature enterprise features, huge ecosystem and hiring pool.

GCP strengths

Global VPC and load balancer, GKE (Kubernetes came from Google), BigQuery, Cloud Run's simplicity, strong data/AI tooling.

Interview angle

Name the category first ("a managed queue"), then the service on the cloud they use. Avoid lock-in where it's cheap to (containers, Terraform, open protocols), accept it where it buys a lot (managed DBs).

Lock it in

Same facilities, different signboards.

EC2 ↔ Compute Engine, S3 ↔ GCS, RDS ↔ Cloud SQL, Lambda ↔ Cloud Run functions, Fargate ↔ Cloud Run, EKS ↔ GKE, SQS ↔ Pub/Sub.

Interview questions

A notable networking difference between AWS and GCP?

An AWS VPC is regional; connecting regions needs peering or Transit Gateway. A GCP VPC is global with regional subnets, so VMs in different regions share one private network, and GCP's external HTTP(S) load balancer has a single global anycast IP.
