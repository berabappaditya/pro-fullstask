The cheat sheet

Every concept in one or two lines, with the chai-stall picture that helps you remember it.

High-Level Design

ch {{n:ch-request}} · request
Request journey

DNS → TCP → TLS → HTTP → server → response → render. HTTP is stateless; cookies/tokens carry identity.

ch {{n:ch-scaling}} · scaling
Vertical vs horizontal

Bigger kettle vs more stalls. Scale out needs stateless servers + shared session store.

ch {{n:ch-scaling}} · latency
Latency vs throughput

One trip's time vs trips per second. Measure p99, not averages. RAM ≫ SSD ≫ network.

ch {{n:ch-lb}} · LB
Load balancer

Bablu at the gate. L4 = IP/port, L7 = URL/headers. RR, weighted, least-conn, IP hash. Health checks.

ch {{n:ch-cache}} · cache
Caching

Flasks on the counter. Cache-aside + TTL + delete on write. LRU eviction. Beware stampede, penetration, avalanche, hot keys.

ch {{n:ch-cache}} · CDN
CDN

Static files cached at edge servers near users. Pull (lazy) or push. Versioned filenames to bust caches.

ch {{n:ch-db}} · db
SQL vs NoSQL

Ledger vs folders. SQL: relations + ACID. NoSQL: key-value, document, wide-column, graph; scale-out, flexible.

ch {{n:ch-db}} · ACID
ACID

Atomic, Consistent, Isolated, Durable. Isolation levels trade anomalies for speed. Optimistic vs pessimistic locking.

ch {{n:ch-db}} · index
Indexes

B+ tree = book index. Fast reads, slower writes. Composite index: leftmost-prefix rule.

ch {{n:ch-replication}} · replication
Replication

One pen, many photocopies. Leader–follower; sync vs async; lag → read-your-writes fixes; quorum R + W > N.

ch {{n:ch-sharding}} · sharding
Sharding

Split the ledger by surname. Range / hash / directory / geo. Shard key from main query. Cross-shard pain.

ch {{n:ch-sharding}} · ring
Consistent hashing

Walk clockwise on the ring. Adding a node moves ~1/N keys. Virtual nodes balance load.

ch {{n:ch-cap}} · CAP
CAP / PACELC

Phone line cut: be correct (CP) or kind (AP). Else: latency vs consistency.

ch {{n:ch-queue}} · queue
Message queues

Slips on the spike. Decouple + absorb spikes. Queue = one consumer, pub/sub = all. At-least-once → idempotent consumers, DLQ.

ch {{n:ch-queue}} · Kafka
Kafka

Topic → partitions (ordered logs) → offsets. Consumer group: one consumer per partition. Replayable.

ch {{n:ch-api}} · API
API styles

Menu board. REST (nouns + verbs), GraphQL (ask for fields), gRPC (fast binary). Cursor pagination, idempotency keys.

ch {{n:ch-api}} · real-time
Real-time

Short poll → long poll → SSE (server → client) → WebSocket (both ways). Webhooks for server-to-server.

ch {{n:ch-micro}} · micro
Microservices

Separate counters with own stock. Own data, independent deploy. Gateway, discovery, config, mesh. Monolith first.

ch {{n:ch-rate}} · rate
Rate limiting

Max 5 cups each. Token bucket (bursts), leaky bucket (smooth), fixed/sliding window. Redis + 429.

ch {{n:ch-reliability}} · resilience
Reliability

Spare cylinder. Redundancy, timeouts, backoff + jitter, circuit breaker (closed/open/half-open), bulkheads, fallbacks.

ch {{n:ch-dtx}} · transactions
Distributed transactions

2PC: ready? go! Saga: do, then undo. Outbox: event in the same DB transaction. CQRS: separate read model.

ch {{n:ch-toolbox}} · toolbox
Toolbox

Snowflake IDs, Bloom filters ("definitely not"), geohash, inverted index, gossip, Raft, object storage + CDN.

ch {{n:ch-security}} · security
Security

AuthN = ID card, AuthZ = room keys, JWT = stamped wristband. OAuth2 code flow. bcrypt, parameterised SQL, HTTPS.

ch {{n:ch-observe}} · observe
Observability

Metrics (is it wrong?), traces (where?), logs (why?). SLI / SLO / SLA, error budget, golden signals.

ch {{n:ch-estimate}} · estimate
Estimation

1 day ≈ 105 s. QPS = users × actions ÷ 105. Peak ≈ 2–3×. Every number → a design decision.

ch {{n:ch-hld-framework}} · framework
HLD interview

Requirements → Estimation → API & data → Design → Deep dives → Wrap-up. Talk trade-offs.

Real-world architectures

ch {{n:ch-netflix}} · Netflix
Brain in the cloud, bytes nearby

Control plane on AWS (Zuul, Eureka, EVCache, Cassandra, Kafka). Data plane: Open Connect boxes inside ISPs, filled overnight. Adaptive bitrate per chunk.

ch {{n:ch-upi}} · UPI
One exchange for every bank

NPCI hub-and-spoke switch, VPA indirection, device binding + PIN, idempotent txn IDs, timeouts, pending → check status → reversal. Rate limits after the 2025 retry storm.

ch {{n:ch-stripe}} · Stripe
Same key, same answer

Idempotency keys, PaymentIntent state machine, tiered rate limiters and priority load shedding, DocDB proxy + shards with zero-downtime moves, signed retried webhooks.

ch {{n:ch-hotstar}} · JioHotstar
Light the stoves before the toss

Spikes faster than boot time: pre-warm by schedule, scale on concurrency in steps, CDN for video and cacheable APIs, full-size load tests, panic mode.

Low-Level Design, SOLID and patterns

ch {{n:ch-oop}} · OOP
A PIE

Abstraction (what, not how), Polymorphism (one call, many behaviours), Inheritance (is-a), Encapsulation (guard the data).

ch {{n:ch-uml}} · UML
Relationships

Triangle = is-a. ◆ composition (dies together), ◇ aggregation (lives on). Dashed = implements / uses.

ch {{n:ch-uml}} · quality
Cohesion & coupling

High cohesion inside, low coupling between. Everything else is a technique for this.

ch {{n:ch-srp}} · S
Single Responsibility

One cook, one stove. One reason (one actor) to change.

ch {{n:ch-ocp}} · O
Open/Closed

Slot menu board. Add a class, don't edit the switch.

ch {{n:ch-lsp}} · L
Liskov Substitution

Replacement delivery boy must ride. Subtypes keep the parent's promises; no surprise exceptions.

ch {{n:ch-isp}} · I
Interface Segregation

Role cards, not one giant job description. Small interfaces per client.

ch {{n:ch-dip}} · D
Dependency Inversion

Standard socket. Business code owns interfaces; DB/email are plugins. Constructor injection.

ch {{n:ch-beyond}} · more
DRY · KISS · YAGNI

One place per rule; simplest thing that works; don't build for imaginary futures. Compose over inherit. Don't talk to strangers.

ch {{n:ch-creational}} · creational
Sita Found A Big Present

Singleton (one), Factory (which), Abstract factory (matching set), Builder (many options), Prototype (copy).

ch {{n:ch-structural}} · structural
Wrap, adapt, simplify

Adapter converts, Decorator adds, Facade simplifies, Proxy guards, Composite nests, Bridge splits.

ch {{n:ch-behavioral}} · behavioral
Who decides, who's told

Strategy swaps how, State swaps who-I-am, Observer shouts, Command queues/undoes, Chain passes along, Template fixes the recipe.

ch {{n:ch-concurrency}} · concurrency
Last samosa

Check-then-act must be atomic: CAS, putIfAbsent, locks, DB conditional update, Redis SET NX.

ch {{n:ch-banking}} · banking
Ledger is the truth

Money value object, double-entry ledger, LSP-safe accounts, lock smaller ID first with timeout, idempotent transfers, rule chain.

ch {{n:ch-iam}} · IAM
Deny wins, silence means no

AuthN chain raises session level; AuthZ walks the resource tree: explicit deny → allow → step-up → default deny. Explain and audit.

ch {{n:ch-parking}} · LLD interview
Nouns, verbs, what changes

Requirements → entities → class diagram → patterns → core code → concurrency and extensions.

The one sentence to remember

Every design is a trade-off. Say what you're trading, and why it's worth it here.
