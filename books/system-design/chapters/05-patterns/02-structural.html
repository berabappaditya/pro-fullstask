Structural patterns: how objects fit together

Structural patterns combine classes and objects into bigger structures while keeping them flexible: wrapping, adapting, simplifying and nesting.

Adapter: make incompatible interfaces work together

At Ramu's chai stall

The new UPI card machine has a USB-C cable; the old billing computer only has USB-A. Ramu doesn't replace either: he buys a small adapter dongle.

Decorator: add behaviour by wrapping

Facade: one simple front for a complicated system

Ramu's mobile app has a single "Order again" button. Behind it: check stock, reserve it, charge the saved card, tell the kitchen, book a rider. The button is a facade.

Proxy: a stand-in that controls access

A proxy has the same interface as the real object and sits in front of it to add control: caching, lazy loading, access checks, remote calls, transactions.

Virtual proxy

Delay creating something expensive (Hibernate lazy-loaded collections).

Protection proxy

Check permissions before calling (Spring Security @PreAuthorize).

Remote proxy

Local object that forwards calls over the network (gRPC stubs, Feign clients).

Caching / smart proxy

Return cached results, count calls, open transactions (Spring @Transactional, @Cacheable).

Decorator vs Proxy: same shape, different intent. A decorator adds features and is usually stacked by the client; a proxy controls access to one subject and is usually invisible to the client.

Composite: treat a group like a single item

The menu has items (Masala chai ₹15) and categories that contain items or other categories ("Combos" → "Breakfast combo" → chai + samosa). You want price() to work on any of them.

Bridge and Flyweight, briefly

Bridge
Split two dimensions that vary independently

Messages (OrderAlert, PromoMessage) × channels (SMS, Email). Instead of 2×2 subclasses, a Message has a Channel. Add a channel or a message type independently. JDBC: the DriverManager/API side and the vendor driver side are a bridge.

Flyweight
Share common state to save memory

Millions of map markers share one icon image object; only position differs. JDK: Integer.valueOf(-128..127) cache, the String pool.

Lock it in

Adapter converts, Decorator adds, Facade simplifies, Proxy guards, Composite nests, Bridge splits.

Adapter = different interface → mine. Decorator = same interface + extra. Proxy = same interface + control. Facade = new, simpler interface over many.

Interview questions

Adapter vs Facade?

Adapter makes one existing interface match another interface that clients already expect; it's about compatibility. Facade defines a new, simpler interface over a whole subsystem; it's about convenience. An adapter usually wraps one object; a facade usually coordinates many.

Where are decorators used in the JDK?

java.io: BufferedInputStream, DataInputStream, GZIPInputStream all wrap another InputStream. Also Collections.synchronizedList() and Collections.unmodifiableList() wrap a list to add synchronization or read-only behaviour.
