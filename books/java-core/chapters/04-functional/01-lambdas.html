Lambdas and functional interfaces

A lambda is a short way to pass "a piece of behaviour" as a value. It fills in the one abstract method of a functional interface.

In Ramu's kitchen

Instead of hiring a whole new chef (a class) every time he needs "add extra ginger", Ramu writes the instruction on a sticky note and hands it to whichever chef is free. The sticky note is a lambda; the slot on the chef's clipboard that accepts exactly one instruction is the functional interface.

Effectively final

A lambda can read local variables from the surrounding method only if they're never reassigned. The lambda captures the value, and allowing changes would create confusing races between threads. Fields and objects' contents can still change.

Interview questions

Is a lambda the same as an anonymous class?

No. A lambda doesn't create a new scope (this refers to the enclosing object), can only implement functional interfaces, and is compiled with invokedynamic rather than generating a separate .class file per use, which is lighter.

Can a functional interface have default methods?

Yes, any number of default and static methods; it must have exactly one abstract method. Predicate.and, Function.andThen are default methods.
