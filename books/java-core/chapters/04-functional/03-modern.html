Modern Java: what changed from 8 to 25

Java ships every six months, with a long-term-support (LTS) release every two years: 8, 11, 17, 21, 25. Know the headline features of each LTS.

In Ramu's kitchen

Ramu's kitchen gets new equipment every season. Most of it is small (a better peeler), but every few years there's a big upgrade the whole chain adopts (an LTS). Interviewers ask "what version do you use and what do you like in it?": have one or two features ready per LTS.

What's new in Java 25 (LTS, September 2025)

JEP 519
Compact object headers

Object headers shrink from 12 to 8 bytes on 64-bit, cutting heap use for object-heavy apps. Opt in with -XX:+UseCompactObjectHeaders.

JEP 514/515
AOT ergonomics and method profiling

Easier ahead-of-time caches that store class loading and JIT profiles from a training run, so services warm up faster.

JEP 521
Generational Shenandoah

The low-pause Shenandoah GC gets a young/old split, now a product feature.

still preview
Structured concurrency, primitive patterns, stable values

Good to name, not to depend on in production. See {{n:ch-juc}} for structured concurrency.

Interview tip

"Why upgrade from 8/11 to 21 or 25?" A strong answer names one productivity win (records, pattern matching), one performance win (virtual threads for blocking I/O, better GCs, compact headers) and one ecosystem reason (Spring Boot 3+ needs Java 17, Boot 4 is built for 17-25).

Interview questions

Is var dynamic typing?

No. The type is inferred at compile time and fixed; var x = 5; x = "a"; doesn't compile. It's only for local variables (and lambda parameters), not fields, method parameters or return types.

What's the difference between a preview feature and a final one?

Preview features are complete but may still change; you need --enable-preview to compile and run them, and they may change in the next release. Final features are permanent parts of the language.
