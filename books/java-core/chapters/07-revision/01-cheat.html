The cheat sheet

Every concept in one or two lines, with the kitchen picture that helps you remember it.

The platform

ch {{n:ch-jvm}} · JVM
How Java runs

javac → bytecode → class loader → interpreter + JIT. JDK ⊃ JRE ⊃ JVM. Universal recipe language.

ch {{n:ch-memory}} · memory
Stack vs heap

Notepad per chef, shelves for all. Stack: frames, locals, per thread. Heap: objects, shared. Always pass-by-value.

ch {{n:ch-types}} · types
Wrappers

Integer cache −128..127: compare with equals. Never unbox a possible null. BigDecimal for money.

ch {{n:ch-strings}} · String
Strings

Laminated card. Immutable, literals pooled, hash cached. StringBuilder in loops.

Object-oriented Java

ch {{n:ch-classes}} · static
static and final

Recipe card vs cup. Static per class, instance per object. Final = no reassign / override / extend.

ch {{n:ch-classes}} · init
Init order

Parent static → child static → parent instance + constructor → child instance + constructor.

ch {{n:ch-inherit}} · types
Interface vs abstract

Can-do contract vs half-built is-a. Records = data, enum = fixed set, sealed = closed family.

ch {{n:ch-equals}} · equals
equals and hashCode

Same label, same rack. Override together, same fields. Keys immutable. Comparator for extra orders.

ch {{n:ch-exceptions}} · errors
Exceptions

Plan for checked, fix unchecked, flee Error. try-with-resources. Wrap with cause.

ch {{n:ch-generics}} · generics
Generics

Compile-time safety, erased at runtime. PECS: Producer Extends, Consumer Super. Invariant.

Collections

ch {{n:ch-collections}} · choose
Which collection

Rail = List, guest list = Set, spice rack = Map, VIP bell = PriorityQueue. Default ArrayList, HashMap, ArrayDeque.

ch {{n:ch-hashmap}} · HashMap
HashMap internals

16 slots, 0.75 load, treeify at 8 (table ≥ 64), double on resize. hash ^ (h>>>16), index = h & (n−1).

ch {{n:ch-lists-trees}} · iterate
Iterators and friends

Fail-fast CME → removeIf. TreeMap for ranges. LinkedHashMap(access order) = LRU. Size-k heap for top-K.

Functional Java

ch {{n:ch-lambdas}} · lambda
Lambdas

Sticky-note instruction. Implements the single abstract method. Supplier, Consumer, Function, Predicate.

ch {{n:ch-streams}} · streams
Streams

Assembly line. Lazy, single-use, never mutates source. groupingBy, toMap with merge, flatMap flattens.

ch {{n:ch-modern}} · versions
Modern Java

8 lambdas · 11 var/HttpClient · 17 records/sealed · 21 virtual threads/patterns · 25 scoped values.

Concurrency

ch {{n:ch-threads}} · threads
Thread lifecycle

NEW → RUNNABLE → BLOCKED / WAITING / TIMED_WAITING → TERMINATED. sleep keeps locks, wait releases.

ch {{n:ch-create}} · create
Creating threads

Recipe on a card: Runnable/Callable on a pool. start() creates a thread, run() doesn't.

ch {{n:ch-sync}} · sync
Synchronization

counter++ = read, add, write. synchronized = atomic + visible; volatile = visible; Atomic = CAS.

ch {{n:ch-deadlock}} · deadlock
Deadlock

Pan before spatula. Four Coffman conditions; break circular wait with lock order or tryLock.

ch {{n:ch-executors}} · pools
Thread pools

Core → queue → max → reject. Bounded queue, named threads, CallerRunsPolicy. Size to cores or I/O wait.

ch {{n:ch-cf}} · async
CompletableFuture

Apply transforms, Compose chains, Combine joins, allOf waits. Own executor, timeout, fallback.

ch {{n:ch-juc}} · JUC
Concurrency toolbox

CHM merge/compute, BlockingQueue, CountDownLatch, Semaphore, ReadWriteLock. Virtual threads for I/O.

ch {{n:ch-bulk-insert}} · Spring
10,000-row insert

Trays of 500, five waiters. @Async worker bean, own @Transactional, allOf.join, batch_size, Hikari ≥ threads.

Under the hood

ch {{n:ch-gc}} · GC
Garbage collection

Mark from roots, sweep the rest. Young often, old rarely. G1 default, ZGC sub-ms pauses.

ch {{n:ch-troubleshoot}} · prod
Troubleshooting

CPU → top -H + jstack. Memory → jstat + heap dump + MAT. jcmd + JFR for everything.
