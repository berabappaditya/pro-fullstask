Memory: stack, heap and references

Each thread has its own stack for method calls and local variables; all objects live on one shared heap. Variables hold references (addresses), not objects.

In Ramu's kitchen

Every chef carries a small notepad: what they're doing right now, quick numbers, and "the big pot is on shelf 7". When a chef finishes a task, they tear off that page. The actual pots and ingredients sit on the shared storeroom shelves, which every chef can reach. Two chefs can have "shelf 7" written on their notepads: both are pointing at the same pot.

Notepad = stack (one per thread, a page per method call). Storeroom = heap (shared). "Shelf 7" = a reference.

Java is always pass-by-value

The value passed for an object is the reference (a copy of the address). You can change the object it points to, but you can't make the caller's variable point somewhere else.

Common trap

"Objects are passed by reference in Java." No: references are passed by value. The swap function swap(a, b) on two objects can never swap the caller's variables in Java.

Stack: per thread, frames, locals, fast, auto-cleaned. Heap: shared objects, GC-managed. Metaspace: class metadata. Java is always pass-by-value; for objects the value is a reference.

Interview questions

Where are static variables stored?

Static fields belong to the class. Since Java 8 they're stored with the class's Class object on the heap, while the class metadata itself lives in Metaspace (which replaced PermGen and uses native memory).

What causes StackOverflowError vs OutOfMemoryError?

StackOverflowError: a thread's stack ran out of frames, usually unbounded recursion. OutOfMemoryError: the heap (or metaspace, or native memory for threads) couldn't satisfy an allocation even after GC, often from a memory leak or undersized -Xmx.

What is escape analysis?

A JIT optimisation: if an object never escapes a method (no reference leaves it), the JVM can avoid allocating it on the heap (scalar replacement) and remove locks on it. Small, short-lived objects can become almost free.
