Interview questions

What is the difference between fail-fast and fail-safe iterators?

Fail-fast (ArrayList, HashMap) track a modification count and throw ConcurrentModificationException if the collection changes outside the iterator. Fail-safe / weakly consistent (concurrent collections) iterate over a snapshot or tolerate changes and never throw.

HashMap vs LinkedHashMap vs TreeMap?

HashMap: no order, O(1). LinkedHashMap: keeps insertion (or access) order with a doubly linked list through the entries, O(1), slightly more memory. TreeMap: sorted by key with a red-black tree, O(log n), supports range queries.
