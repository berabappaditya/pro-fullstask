How this book works

Four parts: how Spring thinks, building REST APIs, working with data, and running in production. Every annotation is explained by what it makes Spring do behind your back.

The Ramu Chai franchise kit

Ramu's chai is so popular that he sells franchises. A new owner gets a kit: a stove already fitted (embedded Tomcat), a manager who hires staff and tells each one who they work with (the IoC container), standard recipes that work out of the box but can be changed (auto-configuration), a front-desk host who sends each customer to the right counter (DispatcherServlet), and a security guard at the door (Spring Security). The owner only writes what's special about their branch.

Spring Boot 4 note

This book is written for Spring Boot 4.x (Spring Framework 7, Java 17–25, Jakarta EE 11), while pointing out where Boot 3 differs, since many companies still run 3.x. The full list of changes is in {{ref:ch-boot4}}. Java concepts this book builds on (proxies, ThreadLocal, thread pools) are in {{xref:java-core/ch-executors}} and nearby chapters.
