Interview questions

@Mock vs @MockitoBean (@MockBean)?

@Mock creates a Mockito mock with no Spring involvement (unit tests). @MockitoBean (Spring Framework 6.2+; replaces Boot's @MockBean, removed in Boot 4) creates a mock and puts it into the Spring ApplicationContext in place of the real bean, for slice and integration tests. Each distinct set of mocked beans creates a new cached context, so keep them consistent.

Why Testcontainers instead of H2 for repository tests?

H2 behaves differently from PostgreSQL/MySQL (SQL dialect, JSON types, locking, constraints), so tests pass and production fails. Testcontainers runs the real database version in Docker, and @ServiceConnection removes the connection boilerplate.
