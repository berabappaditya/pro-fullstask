What's new in Spring Boot 4 (and 4.1)

Boot 4.0 (November 2025) is a generational release on Spring Framework 7: modular auto-configuration, Jackson 3, JSpecify null-safety, API versioning, HTTP service clients, and removal of everything deprecated in 3.x.

In the franchise

Every few years Ramu redesigns the franchise kit. The new one is lighter (you only ship the parts you use), the labels are stricter (null-safety), the old phone-order forms are gone (deprecated APIs removed), and it fits the newest stoves (Java 25).

Interview tip

If asked "what's new?", pick three: modular starters (smaller apps, faster startup), Jackson 3 + JSpecify (safer code, a real migration step), and first-class API versioning + HTTP service clients (less custom code). Then say how you'd migrate: OpenRewrite recipes, the properties migrator module, and a staged rollout. Also good to know: Spring AI 2.0 is built on Boot 4 (see {{xref:ai-engineering/ch-spring-ai}}).

Lock it in

Lighter kit, stricter labels, old forms gone.

Boot 4 = Framework 7, Java 17–25, Jakarta EE 11, Jackson 3, modular starters, API versioning, @MockitoBean, no Undertow.

Interview questions

How would you migrate a Boot 2.7 service to Boot 4?

In steps: Java 17+, then Boot 3.x (javax → jakarta, Security 6 config style, Hibernate 6) using OpenRewrite; then the latest 3.5 with zero deprecation warnings; then 4.0 (starter renames, Jackson 3 imports, @MockitoBean, test package moves, removed properties via spring-boot-properties-migrator). Rely on a good integration test suite and deploy canary first.
