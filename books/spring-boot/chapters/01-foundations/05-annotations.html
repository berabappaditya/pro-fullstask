Interview questions

@Component vs @Bean?

@Component is on a class and is detected by component scanning. @Bean is on a method inside a @Configuration class and you construct the object yourself; use it for third-party classes, or when creation needs logic or conditions.

What does @SpringBootApplication contain?

@SpringBootConfiguration (a @Configuration), @EnableAutoConfiguration and @ComponentScan (from the annotated class's package).

Why is @Configuration proxied?

So that one @Bean method calling another returns the container's singleton instead of creating a new object. Spring subclasses the config class with CGLIB and intercepts those calls. @Configuration(proxyBeanMethods = false) skips the proxy for faster startup when methods don't call each other.
