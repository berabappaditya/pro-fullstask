What are Spring and Spring Boot?

Spring is the framework (IoC, DI, AOP, MVC, data, security). Spring Boot is the opinionated starter kit on top: auto-configuration, starters and an embedded server, so you can run with java -jar.

The franchise kit

Plain Spring is a warehouse of excellent kitchen equipment: you choose every part, wire the gas, plumb the sink and write the manual yourself. Spring Boot is the franchise kit: the same equipment, pre-assembled with sensible defaults, plug in and start serving. You can still swap any part.

Boot = auto-configuration + starters + embedded server + production features. Opinionated defaults, overridable anytime. Non-web apps work too (spring.main.web-application-type=none, CommandLineRunner).

Interview questions

What is "convention over configuration"?

The framework assumes sensible defaults (port 8080, Jackson for JSON, Hikari for connection pooling, component scanning from the main package) so you only configure what differs from the convention.

What are the advantages of an embedded server?

The app is a single self-contained JAR: same artifact in every environment, no server installation or WAR deployment, easy containerisation (one process per container), and server settings live in application properties.
