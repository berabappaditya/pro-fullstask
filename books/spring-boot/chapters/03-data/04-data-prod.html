Interview questions

Optimistic vs pessimistic locking: when to use which?

Optimistic (@Version): no DB locks, detects conflicting updates at commit; best for low-contention data and long user think-time; requires retry/409 handling. Pessimistic (SELECT FOR UPDATE): blocks competing transactions; best for short, high-contention operations like inventory decrements or wallet debits; risk of waits and deadlocks, so lock in consistent order with timeouts.

What is spring.jpa.open-in-view and why disable it?

Open Session in View keeps the Hibernate session (and a DB connection) open until the HTTP response is rendered, so lazy loading works in controllers and Jackson. It hides N+1 queries and holds connections longer under load. Boot warns about it; disable it and fetch needed data in the service.
