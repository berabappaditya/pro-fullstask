The rapid-fire sheet

One-line answers to the questions asked in almost every Spring Boot interview. Each links back to its chapter.

Foundations

ch {{n:ch-spring-vs-boot}}
@SpringBootApplication

@SpringBootConfiguration + @EnableAutoConfiguration + @ComponentScan.

ch {{n:ch-spring-vs-boot}}
Spring vs Boot

Framework vs opinionated kit: auto-config, starters, embedded server, Actuator.

ch {{n:ch-architecture}}
Request flow

Filters → DispatcherServlet → HandlerMapping → controller → service → repository → DB; Jackson writes JSON back.

ch {{n:ch-ioc}}
IoC / DI

Container creates and wires beans. Prefer constructor injection: final, mandatory, testable.

ch {{n:ch-ioc}}
BeanFactory vs ApplicationContext

Basic lazy container vs full container (events, i18n, env, eager singletons). Boot uses ApplicationContext.

ch {{n:ch-lifecycle}}
Lifecycle

Constructor → inject → Aware → BPP before → @PostConstruct → BPP after (proxy) → ready → @PreDestroy.

ch {{n:ch-lifecycle}}
Scopes

Singleton (default, per container), prototype, request, session, application, websocket. Prototype-in-singleton → ObjectProvider.

ch {{n:ch-annotations}}
@Component vs @Bean

Class-level auto-detection vs method-level factory (third-party classes).

ch {{n:ch-annotations}}
@Primary vs @Qualifier

Default among candidates vs explicit pick at the injection point (wins).

ch {{n:ch-annotations}}
@Controller vs @RestController

View names vs @ResponseBody JSON.

ch {{n:ch-autoconfig}}
Auto-configuration

AutoConfiguration.imports + @ConditionalOnClass / OnMissingBean / OnProperty. Your bean wins. --debug shows the report.

ch {{n:ch-config}}
Config precedence

Command line > env vars > profile files > application.yml > defaults. @ConfigurationProperties for groups.

REST APIs

ch {{n:ch-rest}}
PUT vs PATCH vs POST

Replace (idempotent) vs partial vs create (not idempotent). 201 + Location, 204 on delete.

ch {{n:ch-rest}}
@PathVariable vs @RequestParam

/orders/5 vs /orders?status=PAID.

ch {{n:ch-crud}}
Run a Boot app

IDE, mvn spring-boot:run, gradle bootRun, java -jar (fat JAR). Port: server.port.

ch {{n:ch-dto}}
DTOs

Never expose entities. Records for DTOs, MapStruct for mapping, no @Data on entities.

ch {{n:ch-validation}}
Validation

@Valid on @RequestBody. @NotNull ⊂ @NotEmpty ⊂ @NotBlank. Custom: @Constraint + ConstraintValidator.

ch {{n:ch-errors}}
Errors

@RestControllerAdvice + @ExceptionHandler → ProblemDetail (RFC 9457). Never leak stack traces.

ch {{n:ch-http-clients}}
HTTP clients

RestClient (sync), WebClient (reactive), @HttpExchange interfaces. Always timeouts.

Data

ch {{n:ch-jpa}}
JPA vs Hibernate

Specification vs implementation; Spring Data on top.

ch {{n:ch-jpa}}
Fetch defaults

*ToOne EAGER, *ToMany LAZY. Make everything LAZY; fetch explicitly.

ch {{n:ch-jpa}}
N+1

1 + N queries. JOIN FETCH, @EntityGraph, batch size, DTO projection.

ch {{n:ch-repos}}
Repositories

JpaRepository ⊃ paging ⊃ CRUD. Derived names, @Query, @Modifying, Page vs Slice.

ch {{n:ch-repos}}
findById vs getReferenceById

Query + Optional vs lazy proxy (no query until accessed).

ch {{n:ch-transactions}}
@Transactional

Proxy; rollback on unchecked; REQUIRED joins, REQUIRES_NEW suspends; self-invocation and private methods bypass it.

ch {{n:ch-data-prod}}
Locking

@Version optimistic (rare conflicts) vs FOR UPDATE pessimistic (hot rows).

ch {{n:ch-data-prod}}
Prod data

Flyway migrations, ddl-auto validate/none, Hikari pool sizing, open-in-view off.

Production

ch {{n:ch-security}}
AuthN vs AuthZ

Who you are (401) vs what you may do (403).

ch {{n:ch-security}}
JWT

Signed, stateless bearer token. Short expiry + refresh. STATELESS sessions, CSRF off, BCrypt passwords.

ch {{n:ch-aop}}
AOP

Proxy + advice powers @Transactional, @Async, @Cacheable, @PreAuthorize. Calls from outside only.

ch {{n:ch-cache-async}}
Cache annotations

@Cacheable skips on hit, @CachePut refreshes, @CacheEvict removes. Always a TTL.

ch {{n:ch-cache-async}}
@Async / @Scheduled

Bounded executor; cron = sec min hour day month weekday; ShedLock for multi-instance.

ch {{n:ch-actuator}}
Actuator

Only /health exposed by default. Prometheus metrics, probes, /loggers to change levels live.

ch {{n:ch-testing}}
Testing

Unit → @WebMvcTest/@DataJpaTest → @SpringBootTest + Testcontainers. @MockitoBean (Boot 4).

ch {{n:ch-microservices}}
Microservices

DB per service, gateway, circuit breaker, Kafka + idempotent consumers, outbox + saga, tracing.

ch {{n:ch-boot4}}
Boot 4

Framework 7, Jackson 3, modular starters (-webmvc), API versioning, HTTP service clients, no Undertow.

servers
Embedded servers

Tomcat (default) and Jetty in Boot 4; Undertow was removed. Reactive apps use Netty.
