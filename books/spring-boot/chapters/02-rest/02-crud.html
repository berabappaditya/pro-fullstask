Interview questions

Why didn't update() call save()?

Inside a transaction, entities loaded by Hibernate are managed. On commit Hibernate compares them with the snapshot taken at load time (dirty checking) and issues the UPDATE automatically. save() on a managed entity is harmless but redundant.

What is a fat JAR?

An executable JAR built by the Spring Boot Maven/Gradle plugin that nests your classes, all dependency JARs and a launcher, so java -jar app.jar starts the app with its embedded server. For containers, Boot can also extract it into layers for better Docker caching.
