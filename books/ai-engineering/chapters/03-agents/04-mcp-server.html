stdio vs Streamable HTTP transport?

stdio: the host launches the server as a local subprocess and talks over stdin/stdout; simple, for local tools (filesystem, git), credentials from the local environment. Streamable HTTP: the server is a remote web service (POST requests with optional streamed responses); for shared, multi-user servers, needs OAuth-based authorization, and scales like any HTTP API (especially now that the protocol is stateless).
