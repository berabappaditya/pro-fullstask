The cheat sheet

Every concept in one or two lines, with the picture of Ramu's assistant that helps you remember it.

LLMs

ch {{n:ch-ai-landscape}}
Landscape

Hire, don't raise: compose models with prompts, RAG, tools, evaluation. Closed vs open-weight.

ch {{n:ch-llm-basics}}
How LLMs work

Tokens → embeddings → attention layers → next-token probabilities → sample → repeat. Stateless, cutoff, hallucinations.

ch {{n:ch-llm-basics}}
Training

Pre-training → instruction tuning (SFT) → preference tuning (RLHF/DPO); reasoning models add RL.

ch {{n:ch-sampling}}
Sampling

Temperature low = predictable, high = creative; top-p trims the tail. Set max_tokens.

ch {{n:ch-sampling}}
Cost and latency

Pay per input/output token; output costs more. Stream, prompt-cache static prefixes, route to small models, batch.

ch {{n:ch-prompting}}
Prompting

Role, task, context, rules, format, examples. Delimit data. Structured output + validation.

RAG

ch {{n:ch-embeddings}}
Embeddings

Taste map: similar meaning = nearby vectors; cosine similarity; same model for docs and queries.

ch {{n:ch-vector-db}}
Vector DBs

ANN (HNSW) = fast approximate search. Metadata filters for tenant/ACL. pgvector first.

ch {{n:ch-rag}}
RAG

Open-book exam: load → chunk → embed → store; embed query → retrieve → augment → generate with citations.

ch {{n:ch-chunking}}
Chunking

Cut by section, keep titles, overlap a little; 200–800 tokens to start; parent–child; rich metadata.

ch {{n:ch-advanced-rag}}
Advanced RAG

Hybrid (BM25 + vectors, RRF) + rerank; query rewriting, HyDE; GraphRAG; agentic RAG; semantic cache.

ch {{n:ch-rag-eval}}
Evaluation

Golden set: recall@k, groundedness, correctness; LLM-as-judge calibrated with humans; run in CI.

Tools, agents, MCP and production

ch {{n:ch-tools}}
Tool calling

Model emits a call with JSON args; your code validates, authorises and executes; result goes back.

ch {{n:ch-agents}}
Agents

LLM + tools + loop + memory + guardrails. Workflows first; budgets and human approval for side effects.

ch {{n:ch-mcp}}
MCP

Standard socket: hosts' clients ↔ servers (tools, resources, prompts) over stdio / Streamable HTTP, JSON-RPC.

ch {{n:ch-mcp}}
MCP 2026-07-28

Stateless (no initialize, no session id), server/discover, MRTR (input_required), subscriptions/listen, Roots/Sampling/Logging deprecated.

ch {{n:ch-mcp-server}}
Java MCP server

Spring AI MCP server starter + @McpTool/@McpResource; OAuth; test with MCP Inspector.

ch {{n:ch-mcp-security}}
Security

Prompts aren't a security boundary. Least privilege, per-user tokens, confirmations, break the lethal trifecta.

ch {{n:ch-spring-ai}}
Spring AI

ChatClient + advisors (memory, RAG, safety, tools), VectorStore, ETL, MCP starters, evaluators.

ch {{n:ch-llmops}}
LLMOps

Trace, version prompts, eval in CI, guardrails, budgets, fallback models, privacy.

ch {{n:ch-finetune}}
Fine-tune?

Facts → RAG; style/format/cost at scale → fine-tune (LoRA); often both.

ch {{n:ch-ai-sd}}
AI system design

Requirements, numbers, ingestion, retrieval, chat service, LLM gateway, tools, eval, safety, cost.
